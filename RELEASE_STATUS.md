# Release status — 2026-10-19

Native integration PR #1 is merged: https://github.com/AceDataCloud/LangChain/pull/1 . Main contains the chat model, five independent toolkits and bilingual onboarding. This does not make Ace a default upstream provider or an approved LangChain directory entry.

Stable version **0.1.0 is being prepared**, not yet claimed uploaded. The release owner will publish packages after the release PR's CI and normal merge, then read back every package and update this page. No automatic deployment or paid call runs on merge.

All six historical candidate wheels/sdists are on https://github.com/AceDataCloud/LangChain/releases/tag/v0.1.0rc1 . Do not overwrite or relabel these immutable candidate assets.
